# Contributing

We welcome contributions! Please follow these guidelines:

1. **Fork the repository**: Create a fork of the `main` branch.
2. **Create a branch**: Make your changes in a new branch (`git checkout -b feature/my-feature`).
3. **Use conventional commits**: Follow [Conventional Commits](https://www.conventionalcommits.org/) for your commit messages (e.g., `feat: add new feature`, `fix: resolve bug`).
4. **Run tests before opening a PR**: Ensure all tests pass by running the project's test suite (e.g., `pnpm test` and `pnpm run check`) locally.
5. **Open a Pull Request**: Submit a Pull Request against the `main` branch.
