Workflows in `.github/workflows/`:
1. `ci-items.yml`: Triggered on push to `main`, pull_request, or manual dispatch. Purpose: Validates items and checks PR stats.
2. `ci-template.yml`: Triggered on push to `main` or pull_request. Purpose: Builds and tests the repository.
3. `deploy.yml`: Triggered on push to `main` and `develop` modifying src/ and other critical paths. Purpose: Resolves environment targets and deploys worker to Cloudflare, smoke tests it, and tags a release.
4. `items-daily.yml`: Scheduled run and manual dispatch. Purpose: Generates an item automatically via LLM every day.

**Flags:**
- `deploy.yml` deploys on push to `main` and `develop`, which contradicts normal manual-release models.
- `ci-template.yml` overlaps significantly with `ci-items.yml` and testing done in `deploy.yml`.

1. **Fix missing monorepo dependencies for `pnpm install`**
   - **Problem:** `pnpm install` fails due to `file:../../cores/...` being missing in standalone checkouts.
   - **Evidence:** `ERR_PNPM_LINKED_PKG_DIR_NOT_FOUND`
   - **Change:** Provide a setup script to scaffold these mocks or use `workspace:*` properly with a pnpm workspace configuration that ignores them if missing.
   - **Effort:** M
   - **Command:** `pnpm install`

2. **Fix failing tests**
   - **Problem:** 5 test files fail, with 4 tests failing due to missing `vault` mocks/data and unresolvable imports like `@swal/vault/sealedPack.js`.
   - **Evidence:** `vitest` output showing `Error: Failed to resolve import "@swal/vault/sealedPack.js"`.
   - **Change:** Mock `@swal/vault` properly in vitest setup, or conditionally skip vault tests if the environment isn't set up.
   - **Effort:** M
   - **Command:** `pnpm test`

3. **Fix unused variable warnings in typecheck / build**
   - **Problem:** `statSync` and `Question` types are declared but unused.
   - **Evidence:** `astro check` warnings.
   - **Change:** Remove unused imports and types.
   - **Effort:** S
   - **Command:** `pnpm run check`

4. **Update `README.md` test counts and warnings claim**
   - **Problem:** README claims 125 tests and 0 warnings, which is outdated.
   - **Evidence:** `pnpm test` runs 381 tests; `astro check` has warnings.
   - **Change:** Update README.md to reflect current numbers or remove the specific counts to prevent staleness.
   - **Effort:** S
   - **Command:** `cat README.md | grep -E "125 tests|0 warnings"`

5. **Fix Cloudflare API Token dependency in `build`**
   - **Problem:** `pnpm run build` fails at the end trying to start a remote proxy session due to missing `CLOUDFLARE_API_TOKEN`.
   - **Evidence:** `Error reloading remote server: In a non-interactive environment, it's necessary to set a CLOUDFLARE_API_TOKEN`
   - **Change:** Disable the proxy session attempt during CI/build by default unless explicitly requested.
   - **Effort:** S
   - **Command:** `pnpm run build`
