# Security Policy

## Supported Versions

We currently support the following versions for security updates:

| Version | Supported          |
| ------- | ------------------ |
| `main`  | :white_check_mark: |

*Note: As this repository is continuously deployed, the `main` branch (which contains the latest release) is the only supported version.*

## Reporting a Vulnerability

Please **do not** open public issues for security vulnerabilities. Instead, report them privately via GitHub Security Advisories:

1. Go to the "Security" tab of this repository.
2. Click on "Report a vulnerability".
3. Provide details about the vulnerability.

We aim to respond according to the following targets:

- **Acknowledgment:** Within 5 business days.
- **Status Update:** Within 14 days.

We practice coordinated disclosure. At this time, we do not offer a bug bounty program.
